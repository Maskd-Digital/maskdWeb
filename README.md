# Mask'd Website

Company site for **Mask'd** — design & strategy studio.

## Stack

- Next.js (App Router) + React + TypeScript
- Plus Jakarta Sans (style guide)
- Ready for Vercel deployment

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Deploy on Vercel

1. Push this repo to GitHub
2. Import the project in [Vercel](https://vercel.com/new)
3. Framework preset: **Next.js** (auto-detected)
4. Deploy

Or with the Vercel CLI:

```bash
npx vercel
```

## Loading sequence

1. **Desktop-1** — primary blue (`#0108B8`) + white logo  
2. **Desktop-2** — dark (`#0F1628`) + white logo  
3. Reveal homepage
